## 🏛️ Architecture & best practices

| Area | What I use |
|------|------------|
| **Architecture** | Clean Architecture, Onion, Domain-Driven Design (DDD), CQRS |
| **API design** | RESTful APIs, versioning, pagination, validation (FluentValidation), global error handling, OpenAPI/Swagger |
| **Microservices** | Service decomposition, API Gateway, async communication (events / message broker), database per service |
| **Security** | JWT, refresh tokens, role & policy-based authorization, ASP.NET Core Identity, OWASP best practices |
| **Patterns** | Repository, Unit of Work, Mediator (MediatR), Dependency Injection, Options pattern |
| **Quality** | Unit & integration tests (xUnit, Moq), logging (Serilog), health checks |
